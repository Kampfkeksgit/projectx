# Discord Anti-Raid-Bot – Schutz vor Beitritts-Wellen

Schütze deinen Server vor Raids: Der Bot erkennt verdächtige Beitritts-Wellen und junge Accounts und reagiert mit Alarm, Kick oder Ban.

## Was es kann
- Konto-Alter-Gate
- Beitrittsraten-Erkennung (Burst)
- Aktion: Alarm, Kick oder Ban + Alarm-Kanal

## Einrichten
1. Dashboard → **Anti-Raid** aktivieren
2. Konto-Alter, Rate und Aktion setzen → **Speichern**

*Tarif: Basic.*
