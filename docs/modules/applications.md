# Discord Bewerbungs-Bot – Formulare & Prüfung

Sammle Team-/Rollen-Bewerbungen über Formulare mit Fragen (Modal), prüfe sie per Annehmen/Ablehnen und vergib bei Annahme automatisch eine Rolle.

## Was es kann
- Formulare mit bis zu 5 Fragen
- Review-Embed mit Annehmen/Ablehnen
- Rollenvergabe + DM bei Annahme

## Einrichten
1. Dashboard → **Bewerbungen**: Formular anlegen
2. Fragen, Review-Kanal und Rolle setzen
3. `!applypanel` im Server posten

*Tarif: Pro.*
