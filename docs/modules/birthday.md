# Discord Geburtstags-Bot – Glückwünsche & Rolle

Feiere deine Mitglieder: Der Bot speichert Geburtstage und gratuliert automatisch, optional mit einer Geburtstagsrolle für den Tag.

## Was es kann
- `!birthday TT.MM[.JJJJ]` speichert das Datum
- Automatische Ankündigung am Geburtstag
- Optionale Geburtstagsrolle (wird am Folgetag entfernt)

## Einrichten
1. Dashboard → **Geburtstage** aktivieren
2. Ankündigungs-Kanal + optionale Rolle wählen → **Speichern**

*Tarif: Basic.*
