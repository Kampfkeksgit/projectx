# Discord Geplante Nachrichten-Bot

Poste Ankündigungen automatisch – einmalig zu einem Zeitpunkt oder wiederkehrend in Intervallen. Automatisiere Erinnerungen und Updates direkt aus dem Dashboard.

## Was es kann
- Einmalige oder wiederkehrende Nachrichten
- Zielkanal frei wählbar
- Verwaltung im Dashboard

## Einrichten
1. Dashboard → **Geplante Ankündigungen**
2. Kanal, Inhalt und Zeit/Intervall setzen → **Speichern**

*Tarif: Pro.*
