# Discord Vorschläge-Bot – Ideen abstimmen

Sammle Vorschläge deiner Mitglieder in einem eigenen Kanal, jeweils mit Auf-/Abwärts-Reaktion zur Abstimmung. Einfaches Community-Feedback.

## Was es kann
- `!suggest <Text>` postet den Vorschlag als Embed
- Automatische Up-/Downvote-Reaktionen
- Konfigurierbare Vote-Emojis

## Einrichten
1. Dashboard → **Vorschläge** aktivieren
2. Vorschlags-Kanal + Emojis wählen → **Speichern**

*Tarif: Free.*
