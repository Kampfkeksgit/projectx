# Discord Economy Bot – Währung, Daily & Shop

Füge deinem Server eine Wirtschaft hinzu: Kontostand, Daily/Work-Belohnungen, Bezahlen, Bestenliste und ein Rollen-Shop – Shop und Einstellungen im Dashboard verwaltbar.

## Funktionen des Economy-Bots
- Befehle: `!balance !daily !work !pay !rich !shop !buy`
- Konfigurierbare Währung, Start-Guthaben und Cooldowns
- Rollen-Shop (Kauf vergibt optional eine Rolle)
- Guthaben-Bestenliste

## Einrichten
1. Dashboard → **Wirtschaft (Economy)** aktivieren
2. Währung, Daily/Work-Beträge einstellen
3. Shop-Artikel anlegen → **Speichern**
