# Discord Reaktionsrollen & Rollen-Menü Bot

Selbst vergebbare Rollen per Reaktion, Button oder Dropdown. Baue Reaktionsrollen- und Rollen-Menü-Panels direkt im Dashboard – ohne Code.

## Funktionen
- Rollen per Reaktion an einer Nachricht (klassisch)
- Rollen-Menüs mit Buttons oder Dropdown, optional exklusiv
- Menü-Nachricht als Auto-Liste, eigenes Embed oder Components V2
- Live-Update: Änderungen im Dashboard aktualisieren die Nachricht

## Einrichten
1. Dashboard → **Reaktionsrollen** bzw. **Rollen-Menüs**
2. Kanal, Emoji/Label und Rolle je Eintrag festlegen
3. **Speichern** – der Bot postet/aktualisiert die Nachricht

*Tarif: Free (Reaktionsrollen) · Basic (Rollen-Menüs).*
