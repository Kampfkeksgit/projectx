# Discord Autorole Bot – Rollen automatisch beim Beitritt

Vergib neuen Mitgliedern automatisch eine oder mehrere Rollen, sobald sie deinem Server beitreten. Bots optional ausschließen. Set-and-forget im Dashboard.

## Was es kann
- Eine oder mehrere Rollen beim Beitritt
- Bots optional überspringen

## Einrichten
1. Dashboard → **Auto-Rolle** aktivieren
2. Rollen auswählen → **Speichern**

*Tarif: Free.*
