# Discord Umfrage-Bot – Button-Polls mit Live-Auszählung

Erstelle Umfragen mit Buttons und Live-Auszählung, optional mit Ablaufzeit. Schnelle Community-Entscheidungen direkt in Discord.

## Was es kann
- `!poll Frage | A | B | …`
- Live-Tally im Embed
- Timed Polls schließen automatisch

## Einrichten
1. Dashboard → **Umfragen** (Übersicht/Löschen)
2. Umfrage per `!poll` im Server starten

*Tarif: Free.*
