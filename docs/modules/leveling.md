# Discord Leveling Bot – XP, Ränge & Belohnungsrollen

Belohne Aktivität mit XP, Leveln, einer Bestenliste und Belohnungsrollen. MEE6-ähnliches Leveling, komplett über das Dashboard konfigurierbar – kostenlos nutzbar.

## Was der Leveling-Bot kann
- XP pro Nachricht (Bereich + Cooldown), Level-Up-Ankündigung
- Belohnungsrollen pro Level (stapelnd oder nur die höchste)
- Bestenliste (Top 25) im Dashboard
- Ignorierte Kanäle

## Einrichten
1. Dashboard → **Leveling** aktivieren
2. XP-Range, Cooldown und Level-Up-Kanal einstellen
3. Belohnungsrollen hinzufügen → **Speichern**

*Tarif: Basic.*
