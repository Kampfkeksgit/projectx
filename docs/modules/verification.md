# Discord Verifizierungs-Bot – Button-Gate

Schütze deinen Server mit einem Ein-Klick-Verifizierungs-Panel, das neuen Mitgliedern nach Bestätigung eine Verifiziert-Rolle gibt. Gestaltbar als Plain, Embed oder Components V2.

## Was es kann
- Button-Panel, das eine Rolle vergibt
- Auto-Post und Live-Update des Panels
- Kombinierbar mit Anti-Raid

## Einrichten
1. Dashboard → **Verifizierung** aktivieren
2. Kanal, Verifiziert-Rolle und Panel-Text setzen
3. **Speichern** (oder `/verifypanel` im Server)

*Tarif: Free.*
