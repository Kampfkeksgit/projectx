# Discord Starboard-Bot – beste Nachrichten hervorheben

Hebe die besten Nachrichten deines Servers hervor: Ab einer bestimmten Anzahl Stern-Reaktionen landen sie in einem Highlight-Kanal. Custom-Emoji und Schwelle wählbar.

## Was es kann
- Stern-Schwelle + eigenes Emoji
- Repost mit Embed und Jump-Link
- Zähler bleibt aktuell

## Einrichten
1. Dashboard → **Starboard** aktivieren
2. Kanal, Emoji und Schwelle setzen → **Speichern**

*Tarif: Basic.*
