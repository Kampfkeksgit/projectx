# Discord Invite-Tracker – wer wen eingeladen hat

Erkenne, wer wen auf deinen Server eingeladen hat – mit Einlader-Bestenliste und Beitritts-Ankündigungen. Belohne deine besten Einlader. Braucht „Server verwalten".

## Was es kann
- Zuordnung neuer Mitglieder zum Einlader
- Einlader-Bestenliste
- Beitritts-Ankündigung mit Einlader

## Einrichten
1. Dashboard → **Invite-Tracking** aktivieren
2. Log-Kanal + Nachricht wählen → **Speichern**

*Tarif: Basic.*
