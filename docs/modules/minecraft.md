# Minecraft Server-Status Bot für Discord

Zeige den Live-Status deiner Minecraft-Server (Java **und** Bedrock) in Discord – Spielerzahl, MOTD und Version – als sich automatisch aktualisierende Nachricht. Kostenlos.

## Funktionen
- Java- und Bedrock-Server per IP
- Live-Statusnachricht (online/offline), editiert sich selbst
- Darstellung als Klartext **oder** Embed mit Platzhaltern
- Spielerzahl, MOTD, Version, Adresse

## Einrichten
1. Dashboard → **Minecraft-Status** → Server hinzufügen
2. Adresse, Edition (Java/Bedrock) und Kanal wählen
3. **Speichern** – die Statusnachricht erscheint binnen ~2 Min

*Tarif: Free.*
