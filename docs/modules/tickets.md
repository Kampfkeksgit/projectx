# Discord Ticket Bot mit Dashboard – Support-Tickets

Betreibe ein komplettes Support-Ticket-System auf deinem Discord-Server: Panel mit Dropdown oder Buttons, Kategorien, Claim, Bewertungen und Transkripte – alles über das Web-Dashboard konfigurierbar.

## Funktionen des Ticket-Systems
- Panel als Dropdown **oder** Buttons, gestaltbar als Embed oder Components V2
- Ticket-Kategorien mit eigener Support-Rolle, Kanal-Kategorie und Willkommenstext
- Claim, User hinzufügen/entfernen, Schließen mit Bestätigung
- Bewertung (1–5 Sterne), Transkript und Log-Kanal

## Einrichten
1. Dashboard → **Tickets**: Panel-Kanal, Support-Rolle und Kategorien anlegen
2. Panel-Design und Willkommens-Embed gestalten
3. Speichern und im Server `/ticketpanel` ausführen
