# Discord Welcome Bot – Willkommensnachrichten einrichten

Begrüße neue Mitglieder automatisch mit einer Willkommensnachricht, einem gestalteten Embed oder einem Components-V2-Container – optional per DM, mit Bild, Ping und automatischem Löschen. In wenigen Minuten im Dashboard eingerichtet, ohne Code.

## Was der Welcome-Bot kann
- Klartext-Nachricht, Embed **oder** Components-V2-Container beim Beitritt
- Platzhalter wie `{user}`, `{guild}`, `{guild.member_count}`
- Optionale Willkommens-DM, User-Ping und Auto-Löschen nach X Sekunden

## Einrichten
1. Dashboard öffnen → **Begrüßung (Welcome)**
2. Kanal wählen und Modus einstellen (Text / Embed / Components V2)
3. Nachricht in der Live-Vorschau gestalten → **Speichern**
