# Discord Verabschiedungsnachrichten (Leave) einrichten

Poste automatisch eine Nachricht, ein Embed oder einen Components-V2-Container, wenn jemand deinen Discord-Server verlässt. Passendes Gegenstück zum Welcome-Modul, in Minuten eingerichtet.

## Was es kann
- Klartext, Embed oder Components V2 beim Verlassen
- Platzhalter wie `{user.name}`, `{guild}`, `{guild.member_count}`
- Optionales Auto-Löschen

## Einrichten
1. Dashboard → **Verabschiedung (Leave)**
2. Kanal wählen, Modus + Nachricht gestalten
3. **Speichern**

*Tarif: Free.*
