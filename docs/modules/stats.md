# Discord Server-Statistik Bot – Counter-Kanäle

Zeige Live-Serverzahlen als Kanalnamen (Mitglieder, Menschen, Bots, Online, Offline, Booster) plus Verlaufs-Graphen. Der klassische Server-Stats-Bot, online konfigurierbar.

## Was der Stats-Bot anzeigt
- Zähler als Voice-/Text-Kanäle mit Vorlage (`{count}`)
- Online/Offline (Presence-Intent nötig), Booster, Kanäle, Rollen
- Auto-Erstellen der Kanäle in einer Kategorie + Reihenfolge
- Verlaufs-Graphen (7/30 Tage)

## Einrichten
1. Dashboard → **Statistiken** aktivieren
2. Counter anlegen (Metrik, Kanal existierend/auto) → **Speichern**
3. Presence-Intent im Discord-Developer-Portal aktivieren

*Tarif: Pro.*
