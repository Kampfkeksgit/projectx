# Discord Temp-Voice Bot – Join to Create Sprachkanäle

„Join to Create": Mitglieder betreten einen Hub-Kanal und erhalten einen eigenen temporären Sprachkanal mit Steuerungspanel (Sperren, Limit, Umbenennen, Kick). Leere Kanäle werden automatisch gelöscht.

## Funktionen des Temp-Voice-Bots
- Hub-Kanal → persönlicher Sprachkanal in einer Kategorie
- Steuerungspanel: Lock/Unlock, Hide/Show, Limit, Rename, Invite, Kick, Claim
- Automatisches Aufräumen leerer Kanäle
- Panel-Ziel: Sprachchat, DM oder eigener Kanal

## Einrichten
1. Dashboard → **Temp-Voice** aktivieren
2. Hub-Kanal, Kategorie, Namensvorlage und Limit setzen
3. Steuerungspanel optional aktivieren → **Speichern**

*Tarif: Basic.*
