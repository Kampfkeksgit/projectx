# Discord YouTube/Twitch/Kick Benachrichtigungs-Bot

Kündige neue YouTube-Videos und Twitch-/Kick-Livestreams automatisch in Discord an – mit eigener Nachricht und optionalem Embed. Verpasse keinen Upload mehr.

## Was es kann
- YouTube-Uploads (RSS), Twitch- und Kick-Live-Erkennung
- Eigene Nachricht mit Platzhaltern + optional Embed
- Mention-Rolle je Creator

## Einrichten
1. Dashboard → **Social-Benachrichtigungen**
2. Plattform, Account und Kanal hinzufügen → **Speichern**

*Tarif: Pro.*
