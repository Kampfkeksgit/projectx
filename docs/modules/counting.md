# Discord Counting-Bot – Zähl-Spiel im Chat

Betreibe einen gemeinsamen Zähl-Kanal: Der Bot prüft jede Zahl, führt Highscores und setzt bei Fehlern zurück. Einfaches, süchtig machendes Community-Spiel.

## Was es kann
- Validierung jeder Zahl (kein Doppel-Count)
- Highscore und aktueller Stand
- Optionaler Reset bei Fehler

## Einrichten
1. Dashboard → **Counting** aktivieren
2. Zähl-Kanal + Emoji wählen → **Speichern**

*Tarif: Free.*
