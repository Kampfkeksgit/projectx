# Discord Eigene Befehle & Befehls-Manager

Erstelle eigene Text-Befehle und verwalte alle eingebauten Befehle pro Server – mit eigenem Prefix und An/Aus-Schalter je Befehl.

## Was es kann
- Eigene Befehle (exact / contains / starts_with)
- Server-Prefix frei wählbar
- Jeden Built-in-Befehl pro Server an-/ausschalten

## Einrichten
1. Dashboard → **Eigene Befehle**
2. Prefix setzen, Befehle togglen oder eigene anlegen
3. **Speichern**
