# Discord Auto-Moderation Bot – Anti-Spam & Filter

Automatische Moderation für deinen Discord-Server: Anti-Spam, Wortfilter, Anti-Invite/-Link, Massen-Erwähnungen und Caps-Filter, mit Warnungen, Mutes und Timeouts – vollständig im Dashboard konfigurierbar.

## Was die Auto-Moderation filtert
- Anti-Spam (Sliding-Window) und verbotene Wörter
- Anti-Invite, Anti-Link, Anti-Caps, Massen-Erwähnungen
- Aktionen: löschen, verwarnen, muten, kicken, Timeout
- Warn-Eskalation und Ausnahme-Rollen/-Kanäle

## Einrichten
1. Dashboard → **Moderation** aktivieren
2. Filter und Aktionen wählen, Whitelist setzen
3. Warn-Schwelle + Eskalation festlegen → **Speichern**
