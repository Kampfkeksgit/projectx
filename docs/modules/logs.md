# Discord Logging Bot – Audit- & Server-Logs

Protokolliere Ereignisse deines Discord-Servers in einem Log-Kanal: Beitritte, Bans, gelöschte/bearbeitete Nachrichten, Rollen-, Kanal- und Voice-Aktivität. Voller Audit-Trail.

## Was geloggt wird
- Join/Leave, Ban/Unban
- Nachrichten bearbeitet/gelöscht
- Rollen-, Kanal-, Voice- und Member-Updates
- Ignorierte Kanäle

## Einrichten
1. Dashboard → **Server-Logs** aktivieren
2. Log-Kanal + Event-Typen wählen → **Speichern**
